# 黄金项目、资料清单与逐章成果规范

版本：1.0｜作用：为P1选择项目和建立验收目标；本文件不授权把候选资料写入生产facts。

## 1. 项目选择

建议先选广东/惠州单一行政区点型建设项目，确认法律物种、编制阶段、适用时间和规则后再确定报告结构。优先资料完整，而非只看成稿漂亮或项目最简单。

| 必需条件 | 判定方式 | 缺失处理 |
| --- | --- | --- |
| 实际项目与责任主体明确 | 立项/备案、项目名称和范围一致 | 暂不作黄金项目 |
| 原始资料可使用 | 用户确认使用范围和保密要求 | 不上传外部服务，不复制无授权资料 |
| 有当前主体设计 | 图纸/说明/工程量版本及设计阶段可核验 | 列待补资料，不能从成稿倒造设计 |
| 有真实边界与分区材料 | 红线/总平面/竖向/坐标系/空间范围可检查 | 不能用中心点矩形代替 |
| 有专业负责人 | 实际工程师愿意确认资料和复核结果 | 可开发工具，但不能宣称报告专业验收完成 |
| 有目标成果或可建立目标成果 | 已审成果+意见，或工程师确认的拟交付标准 | 成稿仅作表达参考，不自动可信 |

候选：仓库中的惠阳启沃智谷、世维物流等。现有成稿与JSON不自动满足输入条件。惠南源样本为旧报告表压力测试，不得改日期、改物种后冒充新模板黄金报告书。

## 2. 资料清单

每份资料登记document_id、名称、责任单位、版本/日期、原件路径或受控引用、SHA256、适用范围、确认状态、获取权限。扫描件需保留原图，OCR只是转录，未校对数字不得自动进入有效facts。

| 资料包 | 应有内容 | 主要提供/确认角色 | 影响成果 |
| --- | --- | --- | --- |
| D01 基础行政资料 | 立项/备案、用地与建设范围、名称/代码、建设单位、设计阶段、相关批复 | 业主、项目负责人 | 封面、特性表、项目背景、合法性支撑 |
| D02 主体设计 | 设计说明、总平面、竖向、单体/道路/排水/绿化、工程量与设计标准 | 主体设计单位 | 项目概况、措施评价、典型设计引用 |
| D03 空间资料 | 实际红线、永久/临时用地、分区、坐标系、地形/水系/相关底图 | 测绘/GIS、设计单位 | 占地、责任范围、敏感区、附图 |
| D04 土石方 | 分区分项挖填、体积口径、借弃、内部调运、材料利用、时序、运输距离 | 主体设计、施工/业主 | 平衡、借弃合理性、预测和防护 |
| D05 表土调查 | 调查方案/点位、照片、厚度/面积、质量记录、可剥离和就地保护、回覆需求 | 外业人员、水保工程师 | 表土全过程保护利用及平衡 |
| D06 敏感区与手续 | 各适用类型图层/查询、项目位置关系、日期、手续状态、核查记录 | 业主、GIS、水保工程师 | 选址评价和必要的不可避让论证 |
| D07 自然与侵蚀 | 地形地质、气象水文、土壤植被、侵蚀调查/预测依据、时空适用范围 | 专业资料提供方、水保工程师 | 现状、参数、预测方法和设计标准 |
| D08 施工组织 | 分期分区工期、施工道路/场地、工艺、临时用地、堆土时序和容量 | 主体设计/施工组织负责人 | 扰动时段、措施进度、临时防护 |
| D09 措施设计 | 主体已有/新增、功能界定、尺寸/配置、计算或主体设计引用、数量、图纸 | 水保/相关设计工程师 | 措施体系、工程量和投资 |
| D10 价格与费用 | 地区定额版本、材料/人工/机械价格、价格时点、费率依据、年度分配 | 造价人员、水保工程师 | 单价、投资、分年度估算 |
| D11 外部支撑 | 土源、受纳/利用、土地权属、专项论证及相关证明 | 业主及实际责任方 | 借弃来源去向、附件、风险闭环 |
| D12 审查与签署 | 真实专家意见、修改对照、校核审查确认、责任页、签章材料 | 实际编制/校核/审查/批准人员 | 专业验收、定版与最终发布 |

每条缺口记录：gap_id、目标章节/图表、缺什么、为何必要、向谁获取、可接受替代资料、确认人、状态。获取不了的资料应导致具体成果未完成，不以“系统自动估算”默认代替。

## 3. 逐章生产级成果标准

这里描述技术工作单元，不给固定字数；具体适用性和规范要求由项目负责人及水保工程师确认。

| 成果单元 | 不可少的专业内容 | 输出与校核 |
| --- | --- | --- |
| 综合说明/特性表 | 只汇总已确认的项目、评价、表土、借弃、预测、措施、监测、投资及结论 | 与全册数字/口径一致；各摘要反向链接详细结果 |
| 项目概况 | 项目组成、平竖布置、建设内容、施工组织、占地、土石方、进度和自然条件 | 分区/占地/挖填表、必要图件；不能只有总面积和投资 |
| 项目水保评价 | 分别判断选址、布局、占地、土石方、适用取土、施工方法、主体措施 | 问题—证据—方法—优化—结论；缺点需对应后续改进 |
| 表土保护利用 | 调查评价、剥离/就地保护、堆存养护、需求、回覆与余缺 | 调查点图、剥离范围图、平衡和时序，数量/容量一致 |
| 弃渣/临时堆土 | 场址、来源流向、数量、容量、堆置、级别、周边敏感因素、必要专项 | 分场台账、图件和专业论证；不适用需有依据 |
| 流失分析预测 | 现状、扰动因素、分区分时段、方法/参数、计算过程、危害重点 | 预测表可复算；不能默认所有面积都参与恢复期 |
| 防治体系 | 责任范围、水平年、目标、分区、总体布局、工程标准、典型设计和时序 | 一个措施ID关联评价、设计、数量、图和进度 |
| 监测 | 范围/时段、内容/方法/频次、点位设施、实施条件与成果 | 与风险点、防治时序和适用义务一致 |
| 投资 | 依据/说明、工程量、单价、费用、已有/新增、年度安排 | 与措施数量/归属一致；费率与价格有适用版本 |
| 效益 | 治理面积、保护量、植被、减少流失量及适用指标 | 分子分母与口径明确；目标/设计效果/实测分开 |
| 管理 | 组织、后续设计、监测、监理、施工、验收和管护 | 结合项目责任主体、阶段和风险，不只复制通用建议 |
| 附图附件及交付 | 项目支撑文件、必要专项、正式图件、空间数据、签署及版本关系 | 文件齐全可开；正文引用、图号、附件编号和版本一致 |

## 4. 单个章节的“论证卡”模板

```text
内容要求ID / stable section ID：
本节需回答的专业问题：
适用性与规范定位：
本项目资料和版本（文件/页/表/图）：
可确认事实：
待核验、冲突或缺失事实：
采用方法及适用性：
计算过程/主体设计引用：
备选方案与优化（如适用）：
结论和适用限制：
关联表、图、附件、措施ID：
编制/复核记录及输入hash：
任何输入变化后需重做的工作：
```

这是业务工作记录，不直接授权新增另一套措施、投资或事实数据库。P1确认实际需求后，映射到已有实体和必要扩展。

| [巴南石滩项目专家意见](https://www.cqbn.gov.cn/zwgk_252/fdzdgknr/zdxm/pzjgxx_1/fasp/202609/t20260904_16031551.html) | 2026年7月评审、8月报批稿复核、9月公开 | 形成审查问题清单；不是报告全文 |
| [古城路道路工程公示](https://www.stbc.cn/stbc/index/detail?sid=5e636d4bd7f68cd8615e4338c61dec2a) | 2026-07-03公示；附件本次未取得 | 候选，未核验正文，不作训练/验收基准 |

首两份同编制单位同项目群，不算独立多来源。公开网页日期不能证明适用新模板，承诺制公示也不能直接等同审批完成。正文可读不代表原PDF附图附件齐全。

建立黄金样本时记录：publication_date、cover_date、submission_date、approval_status、template_version、completeness、source_verified、known_issues、allowed_usage。数值和句子不能迁移成新项目事实。

遵守来源治理：本次发现疑似差异的公开文本只作研究候选，不进入生产RAG或规则。负例使用原创合成场景；真实问题稿需按既有治理禁止入库，除非另行批准隔离研究方案。

## 6. 验收组织

第一次完整交付时，要求工程师按以下问题回答，不仅给总分：

1. 哪些事实尚无法确认？哪些结论缺证据？
2. 哪些计算无法独立复算，或方法/参数不适用？
3. 哪些措施设计不足以支撑工程量、施工或投资？
4. 哪些文表图或附件前后不一致？
5. 哪些内容需要结构性重写，而非文字编辑？
6. 哪些人工工作由系统真正减少，哪些只是转移到核查环节？

记录严重度、责任项、修改、重算范围、复核结论和版本。未解决的重大问题不得被平均分掩盖。实际签署人必须知悉生成方式及未自动验证的范围。

## 7. P1退出交付物

- 经确认的项目支持范围和适用规则版本。
- 原始资料目录、有效版本、数据使用权限及缺口清单。
- 逐章内容要求与论证卡；图表附件清单。
- 人工确认的关键计算/结果与已知争议，不以样稿值自动充当expected。
- 一个可重放的项目输入包；来源与真实性状态完整。
- 经批准的P2文件级实施任务和专业验收人安排。

如果只有成稿、没有输入，交付物应标“反向拆解参考集”，不是黄金端到端测试集。
