## 9. 章十 水土保持投资估算及效益分析（**3 个一级子节**）

10.1 编制依据 — 11 条文件清单（**定额 + 收费标准 + 价格信息 + 补偿费规范**）

  - 关键文件：发改价格 [2007]670 号《建设工程监理与相关服务收费管理规定》
  - 关键文件：计价格 [2002]10 号《工程勘察设计收费标准》
  - 关键文件：**粤发改价格【2021】231 号** 补偿费征收标准（与 [[primary_industry]] / [[huizhou_physical_ranges]] 已知）
  - 主要材料价格：惠州市 2022.4 信息价

10.2 基础单价编制 — 3 子节
  - 10.2.1 主要构成（**水保投资 7 部分**：工程措施费 / 植物措施费 / 监测措施费 / 施工临时措施费 / 独立费用 / 预备费 / 水土保持补偿费）
  - 10.2.2 计算依据（**8 大块**：人工预算单价 / 材料预算价格 / 工程单价 / 工程措施费 / 植物措施费 / 监测措施费 / 施工临时工程 / 独立费用 / 预备费 / 水土保持补偿费）
    - 人工：惠州三类地区，技工 98.3 元/工日，普工 70.4 元/工日
    - 材料：42.5 水泥 0.56 元/kg，柴油 7.35 元/kg，砂 296 元/m³
    - 工程单价公式（多层嵌套）：`单价 = (直接工程费 + 间接费 + 利润 + 主要材料价差 + 未计价材料费 + 税金) × 110%`
      - 直接工程费 = 直接费 + 其他直接费(5%)
      - 间接费：土方开挖 9.5% / 土石方填筑 10.5% / 植物 8.5% / 其他 10.5%
      - 利润：直接工程费+间接费 之和 × 7%
      - 税金：直接费+间接费+利润+主要材料价差+未计价材料费 × 9%
    - 监测措施费：土建+设备+人工三段，**表 10.2-1 详细构成**（GPS 5000 / 计算机 7500 / 无人机 5000 / 烘箱 625 / 天平 375 / 植被测量 500 + 消耗性材料 1055 + 监测期人工费按工程师 2 万/年·人，监测员 1 万/年·人）
    - 独立费用：建管费 3% / 经济技术咨询费(技术 0.5% + 方案咨询取市场价 10 万) / 监理 670 号文 / 造价咨询 / 设计费 / 验收咨询 10 万
    - 预备费：基本预备 10%，价差预备不计
    - **补偿费按 0.6 元/m²**（粤发改 [2021] 231 号），本例 7800 × 0.6 = 4680 元 = 0.468 万元；但**减免后实缴 0.0468 万元**（10%上缴中央，地方 90% 免征 — 财综 [2014] 8 号 + 惠市发改价 [2014] 30 号）

  - 10.2.3 水土保持投资主要指标（**总结段** + 表 10.2-3 总投资估算 + 表 10.2-4 新增措施投资 + 表 10.2-5 主体已列措施投资 + 表 10.2-6 新增措施分部工程投资 + 表 10.2-7 独立费用/预备费估算 — **5 张投资表**！）

10.3 防治效果 — **六率达标复核**
